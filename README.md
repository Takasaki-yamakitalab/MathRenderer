# MathRenderer

簡易的な数式組版エンジン

- 数式をBMP上にレイアウトする
- C++標準ライブラリのみ使用
- 入力トークン列をSciCalc用の数式に変換可能

# Installation

MSVCの場合
```
mkdir build
cd build
cmake ..
cmake --build . --config Release
cmake --install .
```

GNUCの場合
```
mkdir build
cd build
cmake ..
cmake --build .
cmake --install .
```

# Description

数式をレイアウトし、ビットマップ画像に書き出します。

トークン列の作成に関しては、`process_input()`関数の使用が推奨されます。
これは、特殊関数の`{}`の個数や、未定義トークンといった構文のエラーを防ぐためです。

MathRendererは、入力トークン列に構文エラーが一切存在しないことを前提として動作しています。
言い換えれば、MathRendererは入力に対して構文エラーのチェックを行いません。
これは、トークン列の編集を`process_input()`によって管理、制限しているためです。
そのため、MathRendererの機能を拡張する際は、`process_input()`が正常に動作することに注意してください。

代表的なコマンド例は以下の通りです。

- カーソル移動
    - `left`
    - `right`
- カーソルの手前のトークンを削除
    - `del`\
    特殊関数の末尾の`}`の直後で使用した場合、特殊関数を引数ごと削除します。
- 全トークンの削除
    - `ac`
- 数学関数の挿入
    - `mf_***`\
    MathRendererでは、数学関数のマークとして`@`の代わりに`mf_`が使用されます。
    存在しない関数の場合は無視されます。
- 特殊関数の挿入
    - `sf_***`\
    MathRendererでは、特殊関数のマークとして`\\`の代わりに`sf_`が使用されます。
    この際、適切な個数の`{}`が自動的に挿入されます。
    存在しない関数の場合は無視されます。
- 特殊な定数の挿入
    - `const_***_***`\
    定数は、`const`から始まり、属性、名前の組み合わせで表現されます。
    たとえば円周率は`const_mt_pi`となります。
    この例では、`mt`は数学定数であることを表し、`pi`が名前を表します。
    詳細は`math_renderer_input.cpp`を見てください
- ギリシャ文字の挿入
    - `alpha`
    - `beta`
    - 読みを小文字のアルファベットで入力してください。
    なお、頭文字を大文字にすることで、大文字のギリシャ文字が表示されます。
- その他文字の挿入
    - `a`
    - `1`
    - 1文字ずつ入力してください。
